# pde-review-sandbox

Private sandbox for trying the [Tau Ceti review engine](https://github.com/TauCetiProject/TauCetiReview)
on files from the group's `pde_ai` project (https://github.com/chenwydj/pde_ai).
`main` holds only the Lake skeleton; each PR adds one file so the reviewers see it as a diff.
